# 资料口径

所有长度均以毫米表达，试穿 lower_mm 和 upper_mm 用该行 sku/version 的量表。method 说明测的是手围、指长或掌宽。reference 是同一天取得的实测对应，可通过共同试穿提供另一种量表联系。量表版次按实际出库印刷版本，不用今天的标注覆盖历史订单。单边未知不代表已经认定适合。
同一购买凭证上的左右订单 partner 互指，limits 是凭证共用补偿上限，不按行重复，人民币结算，已承担的运费或差额计入。部分换货允许，但替换款的适配范围要与其配对件有交叠。原柜台售后通知对已受理在途业务有效，变更需其确认。标注争议在有证据证明原标注失准后才可进入商家或品牌分担。
